Problem Statement: Develop a clean, user-friendly, and scientifically rigorous web application that consolidates Machine Learning laboratory experiments into one unified platform. The application enables students and faculty to explore datasets, train supported models with zero data leakage, execute live predictions, evaluate held-out performance metrics, and visualize complex decision boundaries through an integrated analytics dashboard.

Laboratory Objectives

  • Consolidate 11 Machine Learning practical experiments into a single cohesive platform.
  • Provide interactive prediction forms connected to validated pre-trained model artifacts.
  • Support explicit model training with configurable train/test splits and hyperparameter tuning.
  • Display verified evaluation metrics strictly calculated on held-out test data.
  • Generate specialized interactive scientific visualizations for every experiment (ROC curves, PR curves, 2D decision boundaries, residual plots, tree structures, feature importances).
  • Explore raw datasets with correlation heatmaps, feature distribution histograms, and summary statistics.
  • Empirically compare compatible models on identical benchmarks.
