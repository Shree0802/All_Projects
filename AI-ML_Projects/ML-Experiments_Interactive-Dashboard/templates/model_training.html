Scientific Training Methodology

Zero Data Leakage: All feature transformations and scaler estimations are strictly computed on X_train and applied onto X_test.

Stratified Splitting: Classification datasets apply stratified sampling to preserve original target class balances across train and test partitions.

Artifact Preservation: Original pre-trained model files are never overwritten; new training outputs are saved in models/trained/ with full parameter metadata.

Direct Evaluation: Once training completes, the application automatically redirects to the unified results dashboard displaying all experiment-specific interactive Plotly charts.
